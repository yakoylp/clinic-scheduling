# 门诊排班

一个本地离线的门诊医生排班小工具：用可视化表格排好某个月的医生出诊安排，一键导出成
标准格式的排班表（Excel）。适合医院门诊、诊所等需要按月排班的场景，**不限于某个科室**。

- **纯本地**：不联网、不上传，所有数据只存本机文件
- **可视化排班**：表格里点选医生、拖动刷格子，像用画笔一样排班
- **出诊时间灵活**：支持医生级周规律（某医生工作日 8:30、周末 8:00）和单格级覆盖，不必全科室一刀切
- **按模板导出**：导出表沿用你提供的模板结构、字体、列宽，日期保持文本格式
- **科室无关**：科室名、诊室、班次时间、医生名单全部自己配，代码里没有任何预设
- **能导入旧表**：如果已有横向网格排班表（日期一列、上午/下午、诊室按列），可以直接导入

## 快速开始

需要 Node.js 16 以上（只用来跑这个桌面应用）。

```bash
git clone https://github.com/yakoylp/clinic-scheduling.git
cd clinic-scheduling
npm install
npm start
```

Windows 上也可以直接双击 **`启动排班软件.bat`**：没装依赖时会提示自动安装，装好后直接开窗口。

## 三步用起来

### 1. 建诊室

「诊室设置」页里一行 = 排班表的一列。

| 字段 | 说明 |
| --- | --- |
| 简名 | 排班表列头显示的短名，例如 `诊室1` |
| 诊室名称 | 导出表「诊室名称」列用的全名，例如 `心血管内科诊室1` |
| 该诊室常驻医生 | 选一位，会把该医生的「默认诊室」同步成这个诊室 |

用 ↑ ↓ 调整列顺序，顺序就是导出时同一班次里各诊室的排列顺序。

改动**自动保存**，页面右上角显示「有改动，正在自动保存…／已自动保存」。

### 2. 录医生

「医生资料」页，每位医生五项：

| 字段 | 说明 |
| --- | --- |
| 姓名 | 只在软件界面显示 |
| 门诊编号 | 导出表「坐诊医生编码」列，**留空则导出该格为空** |
| 号别名称 | 导出表「号别名称」列，例如 `医师`、`副主任医师` |
| 默认诊室 | 导出时用的诊室 |
| 出诊时间 | 默认跟班次时间；个别医生有固定习惯可以按星期几另配，见下面「出诊时间」一节 |

改动**自动保存**，不用点保存按钮。医生颜色点小圆点选，会用在排班表格子上。

### 3. 排班 + 导出

「排班表」页：

- 在表格**下面一排**点一位医生选中（顶部会显示当前画笔）
- 点空格子填人；按住鼠标左键拖动可连续排
- 对同一位医生连点两次 = 清空该格（橡皮擦）
- 右键菜单：清空单格 / 清空整列诊室 / 自定义这一格的时间 / 把这一格的人当画笔
- 侧栏实时显示每位医生班次数、每个诊室占用率、缺编号缺号别的提醒

排完点右上角 **「导出排班表」**：弹窗里先选导出文件夹和文件名，同时给你看这次导出多少行、
每列数据从哪来、有没有要留意的地方，确认后写文件。**导出只新建文件，不会改你原来的表。**

快捷键：`Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做、`Ctrl+S` 保存、`Ctrl+E` 导出、`Ctrl+I` 导入旧表、`Esc` 取消画笔。

## 出诊时间

不同医生、不同日期的出诊时间往往不一样。时间按**三层优先级**决定，下层被上层覆盖：

```
格子级设置  >  医生级周规律  >  科室设置里的班次默认时间
```

### 医生级周规律（按星期几）

适合「每周固定如此」的习惯，比如某位医生**周一到周五上午 8:30 开始、周六日 8:00 开始**。

「医生资料」页点该医生那行的「出诊时间」按钮，弹窗里：

- 用「工作日（一~五）」「周末（六日）」「每天」快捷加一条规则，再改时间
- 每条规则的上午/下午**开始和结束时间都能改**（要 `08:30–11:30` 也行）
- 规则**从上往下**匹配，某天某班次命中第一条就停；没命中的沿用班次默认
- 配的是星期几，所以**跨月、换年份都不用重设**

### 格子级设置（只改某一格）

适合临时变动，比如某天只上半天。在排班表里**右键那个格子 → 「自定义这一格的时间…」**，
填这一格的开始/结束时间。弹窗里可以一键套用「班次默认」或「这位医生的规律时间」。

- 优先级最高，只影响这一个格子，不动医生规律，也不动班次默认
- 右键菜单会多出「清除这一格的时间设置」，点一下回到上层规则

### 怎么看哪个格子时间不一样

格子左上角会标出这格实际的开始时间：

- **浅蓝标记**：按这位医生的周规律出诊
- **实心蓝底标记**：这一格单独设过时间

鼠标悬停能看到完整起止时间。导出时「班次开始时间／结束时间」两列用的就是这个算出来的时间。

## 导出格式

导出一张单 sheet 的表：第 1 行表头，第 2 行起「一个诊室的一个班次」占一行，共 10 列。

| 列 | 来源 | 示例 |
| --- | --- | --- |
| 号源日期 | 排班日期 | `2027-03-01` |
| 班次 | 上午 / 下午 | `上午` |
| 班次开始时间 | 日期 + 这一格算出的开始时刻（见「出诊时间」） | `2027-03-01 08:00:00` |
| 班次结束时间 | 日期 + 这一格算出的结束时刻 | `2027-03-01 12:00:00` |
| 机构名称 | 「科室设置」（可留空） | — |
| 坐诊科室名称 | 「科室设置」 | `心血管内科` |
| 坐诊医生编码 | 医生资料 · 门诊编号 | `doctor001` |
| 号别名称 | 医生资料 · 号别名称 | `医师` |
| 诊室名称 | 该班次所在诊室的全名 | `心血管内科诊室1` |
| 分诊台名称 | 「科室设置」 | `门诊分诊台` |

排列顺序：日期从早到晚 → 同一天先上午后下午 → 同一班次按诊室设置里的顺序从左到右。
**没排班的格子不会出现在导出表里。**

### 导出格式是怎么保证的

`门诊排班模板.xlsx` 是仓库里带的**示例模板**（数据是虚构的，结构和真实模板一致）。
导出时程序以它为底板重写数据区，用 Python + openpyxl 操作，所以表头字体、居中、列宽、
文本格式都会保留——日期不会被 Excel 自作聪明转成序列号。

如果没有 Python / openpyxl，会退回纯 JS 写表：行数和列结构正确，但样式退回 Excel 默认。

| 平台 | 可用的 Python |
| --- | --- |
| Windows | 打包版自带 `runtime/python`；源码方式用系统 Python + `pip install openpyxl` |
| macOS / Linux | 系统 `python3` + `pip3 install openpyxl` |

也可以用环境变量 `DSH_PYTHON` / `PYTHON` 指定解释器。

## 导入旧排班表

如果已经有一份横向网格的老排班表，可以按 `Ctrl+I` 导入。程序能识别这种结构：

- A 列日期（Excel 日期序列号或「3日」这类文本都认）
- B 列星期（可选）
- C 列「上午 / 下午」，每天两行
- D 列起是各诊室，表头那行写诊室名或该诊室常驻医生名，格子里写医生姓名

导入前会显示识别结果（月份、天数、格数、诊室列、跨诊室替班提醒），确认后才写入。
医生字典里同名的会复用，缺的自动补一条（编号/号别留空，到「医生资料」里补）。

`scripts/make-bad-fixture.js` 会生成一份「有毛病」的示例表（整列没人、某天不排、异常文本），
用来试导入容错。

## 数据放在哪

源码方式运行时，数据在项目目录下：

```
data/doctors.json    医生字典
data/schedule.json   诊室、班次、科室设置、每个月每个格子的排班
```

打包成 exe 运行时程序目录只读，数据会放到系统用户数据目录：

| 平台 | 位置 |
| --- | --- |
| Windows | `%APPDATA%\门诊排班\data\` |
| macOS | `~/Library/Application Support/门诊排班/data/` |
| Linux | `~/.config/门诊排班/data/` |

写入用的是「先写临时文件再替换」，不会写一半把数据写坏。
想恢复出厂状态（无医生、无诊室、无排班，只留班次时间）：

```bash
npm run reset
```

## 打包成桌面应用

Windows：

```powershell
pwsh -ExecutionPolicy Bypass -File build-windows.ps1
```

产物在 `dist/`：

- `门诊排班-便携版-x.y.z.exe`：单文件，双击即用；每次运行会解压到临时目录
- `dist/win-unpacked/`：**推荐分发这个**，整个文件夹拷走即可，导出文件会落在它旁边

打包前脚本会尝试下载一份便携版 Python 到 `runtime/python`（约 12MB），
这样对方电脑没装 Python 也能导出保样式的表格；加 `-SkipPython` 可跳过。
打包时**不会**把 `data/`、`导出/` 打进去，避免把本地数据带出去。

### 排班表格的实现注意

排班表是用 CSS Grid 画的（不是 table）。行高统一由 `#gridScroll .grid-body` 上的
`grid-auto-rows` 决定，**单个格子不要再写 `height`**——否则日期列、空诊室格和医生格会各自
撑出不同高度，看起来就像颜色块没对齐。改样式后请跑 `npm run test:ux`。
